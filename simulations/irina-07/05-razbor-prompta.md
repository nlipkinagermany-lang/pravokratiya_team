## 2. Где промпт и персона расходятся (решить авторам)

1. **Подтверждение реального дохода.** Карточка персоны ждёт этот вопрос от интервьюера на шаге 1. Промпт запрещает его в основном потоке («меняет только то, как доказывать»). Либо поправить ожидание в карточке, либо добавить исключение для неофициального дохода плательщика — вопрос определяет форму алиментов.
2. **Имущество юрлица.** В правилах нет ничего про машину на балансе ООО. Модель ответила по здравому смыслу; стоит добавить в справочник одну строку.
3. **«К юристу».** Карточка ждёт совета обратиться к юристу по дому; промпт предусматривает его только для вопросов вне справочника.

## 3. Наблюдения по самому промпту

1. **Таблица шага 5 против лимита «два вопроса на объект».** Для квартиры в браке таблица даёт три вопроса (деньги, ипотека, маткапитал). Пришлось пропустить ипотеку; Ирина сама сказала «без ипотеки», поэтому ничего не потеряли. Нужен приоритет вопросов.
2. **Обещание «ещё минут десять».** По симуляции от согласия до сводки — 28 реплик помощника. Даже с короткими ответами это не 10 минут. Ирина дошла, но на вопросе «сколько ещё» была на грани ухода.
3. **Ответ «число» работает.** Правило «на вопрос „сколько ещё“ всегда отвечай числом» — самое ценное место для удержания человека. Стоит показывать счётчик заранее («вопрос 4 из 11»), чтобы не доводить до этого вопроса.
4. **Проверка по списку без пользы для Ирины.** 5 из 11 вопросов (ценные вещи, брачный договор, банкротство, заграница, здоровье) дали «нет». При этом поручительство нашлось только благодаря слову «поручительства» в тексте вопроса 7. Список надо сохранить, но можно объединить «нет-вопросы» в один («Есть ли что-то из этого: ...»).
5. **Тон.** Правило «не называй и не отражай чувства» выполнено, и персона оценивает его как «сухо». Это сознательная цена правила; решить, нужна ли одна нейтральная фраза в начале.
6. **Цифры.** Промпт разрешает простой расчёт «примерно». В прогоне дан только расчёт алиментов. Для квартиры («около 5,5 млн на каждого») модель не стала считать, хотя правило это допускает. Ирина этого хотела.
7. **Выдача файла.** Промпт запрещает говорить «создала файл», если нет инструмента. В симуляции файл имитирован по просьбе; в реальном чате без инструментов вместо файла будет текст сводки.
